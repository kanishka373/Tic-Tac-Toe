# 🎮 Neon Tic Tac Toe

A neon-themed Tic Tac Toe game built with HTML, CSS and vanilla JavaScript.

## Features
- 2 Player mode
- Play vs Computer (Easy and Hard)
- Hard mode uses the Minimax algorithm, so the computer never loses
- Scoreboard for X, O and draws
- Sound effects with a mute button
- Neon UI with animated background and glow effects

## How to Play
1. Choose a mode from the dropdown
2. Click any cell to place your mark
3. Get 3 in a row to win

## Tech Stack
HTML, CSS, JavaScript (no libraries)
